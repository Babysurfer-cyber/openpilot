# 차선변경 속도 미리 맞춤

FrogPilot의 Human-Like Lane Changes를 C3-wip 기반 구조에 맞게 이식한
선택 기능입니다. 차선변경이 진행되는 동안 이동할 차로의 앞차를 미리
고려하여 속도를 맞춥니다. 조향 궤적이나 차선변경 허용 조건을 바꾸는 기능은
아닙니다.

당근 설정의 **조향일반 → 차선변경 속도 미리 맞춤(0)**에서 설정합니다.
실제 설정 파일은 `selfdrive/carrot_settings.json`이며 네이티브 설정 메뉴에도
같은 항목이 있습니다. `HumanLikeLaneChanges`는 0: 끔(기본값), 1: 켬이고
재부팅 없이 반영됩니다. 진행 중 켜면 현재 차선변경에는 뒤늦게 개입하지 않고
다음 차선변경부터 유효한 관측을 확보합니다. 끄면 즉시 기존 계산으로 돌아갑니다.

## 적용 방식

- 기존 전방 앞차가 있고 오픈파일럿이 종방향·횡방향 제어 중이며 ACC 모드일 때
  사용합니다. 모델 상태가 `laneChangeStarting`인 동안만 추가 대상을 사용합니다.
- 차선변경 전에 목표 차로에서 연속 관측한 실제 레이더 트랙의 식별자를
  보관합니다. 차선변경 중에는 그 차량의 최신 거리·속도·가속도를 사용하며,
  새로 나타난 다른 차로 차량을 대상에 끼워 넣지 않습니다.
- 전방 레이더와 코너레이더는 `(radarSource, radarTrackId)`로 구분합니다.
  기존 RadarD와 궤적 기반 DPathRadarD가 발행하는 데이터 모두를 사용합니다.
- 원본은 목표 차로 차량으로 `leadTwo`를 교체합니다. 이 브랜치는 `leadTwo`를
  끼어들기·정지차 대응에도 사용하므로, 이를 보존하고 MPC에 별도의 장애물
  제약을 추가합니다. 전방 앞차·기존 보조 앞차·정지선·크루즈 속도 제약은
  계속 독립적으로 계산됩니다. 공개 계획 소스는 기존 `lead1` 열거값을 사용합니다.
- 원터치 레버를 계속 누르는 연속 차선변경에서는 모델의 다음 변경 경계
  신호를 확인하고 새 차로 대상을 다시 확보합니다. 한 번의 원터치, 추가
  원터치 예약, ATC, BSD, 실선 판단, 깜빡이 유지 및 계기판 CAN은 수정하지 않습니다.

## 관측이 불확실한 경우

모델과 레이더의 시각을 맞추고 최근 0.25초 이내 수신 데이터와 CAN 상태를
확인합니다. 차로 경계의 확률·폭·좌표, 트랙의 연속성과 수치가 유효하지
않으면 추가 대상을 사용하지 않습니다. 양쪽 경계 확률이 0.5를 넘어야 하므로
차선이 없거나 외측 경계가 불명확하면 기존 제어를 그대로 사용합니다.

처음에는 1m/s 이상 움직이는 차량만 확보하지만, 확보한 차량이 차선변경
도중 정지하면 계속 추적합니다. 트랙 소실·불연속·방향 변경·취소·브레이크·
가속페달·반대 방향 운전자 토크에서는 추가 대상을 해제합니다.
기존 앞차와 같은 대상이면 중복으로 추가하지 않습니다.

기존 끼어들기 사전 감속 제한, FCW의 전방 앞차 판정 및 차량 AEB 경로는
변경하지 않습니다. 추가 장애물이 MPC의 예측 주행 궤적에 영향을 주므로,
모든 상황에서 감속이 더 약해진다는 의미는 아닙니다. 차량에서의 승차감과
실제 개입 시점은 별도 주행 확인이 필요합니다.

## 검증

- 새 선택기·플래너·MPC 연결 테스트 115개와 기존 레이더·BSD·차선변경·
  신호 출력·현대 CAN 회귀 테스트 468개 통과.
- 테스트는 네이티브 cereal 메시지와 실제 Python 계산을 사용했습니다.
  호스트에서 없는 Params/msgq 바인딩은 대체했으며, 제어기 연결 테스트의
  기록용 최적화기와 별도로 네이티브 acados 계산도 수행했습니다.
- 네이티브 MPC 총 7,005회 계산에서 오류 상태나 비정상 수치가 없었습니다.
  25개 비교 시나리오에서 기존 위험 차량과 기본 OFF 동작을 확인했습니다.
  합성 주행의 느린 목표 차로 차량 사례에서는 감속 시작이 2.35초 빨라지고
  최대 감속이 -1.37에서 -1.08m/s²로 줄었습니다. 이 수치는 해당 시나리오의
  결과이며 다른 주행 상황의 감속량을 보장하지 않습니다.
- 기존 로그 1,135프레임의 OFF 결과는 변경 전과 일치했습니다. 같은 로그의
  차선변경은 외측 차선 확률이 약 0.21~0.25라 ON에서도 추가 대상을 사용하지
  않았습니다. 따라서 이 재생은 관측 불확실 시 기존 제어로 돌아가는 동작을
  검증하며, 실차에서의 추가 기능 개입을 입증하지는 않습니다.

장치 전체 빌드와 실제 조향·액추에이터를 포함한 차량 주행 검증은 수행하지
않았습니다.
