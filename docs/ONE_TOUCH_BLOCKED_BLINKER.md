# 차선변경 보류 시 원터치 깜빡이 연장

차량의 원터치 깜빡이 설정이 **3회**인 EV6 CAN-FD Camera-SCC 경로에
기본 3회와 추가 2회, 총 5회의 점멸 기회를 제공합니다.
새 설정 옵션은 없으며 기존 차선변경 허용 조건은 유지합니다.

- 물리 레버를 원터치하고 놓은 요청이 BSD 또는 실선 때문에
  `preLaneChange`에 머물 때만 적용합니다.
- 추가 점멸 중에도 같은 차선변경 요청을 유지합니다. BSD·실선 조건 등이
  해제되어 기존 시작 조건을 만족하면 새 레버 입력 없이 차선변경을 시작합니다.
- 같은 원터치로 연장을 반복하지 않습니다. 재사용하려면 새 물리 레버 조작이 필요합니다.
- 레버를 완전히 체결하거나 1단을 누르고 있는 경우, ATC만의 요청,
  단순 토크 대기·지연·차로 없음에는 이 연장을 적용하지 않습니다.

`DesireHelper`는 기존 FSM의 최종 보류 사유만 `modelV2.meta.laneChangeBlocked`로
알립니다. 현대 컨트롤러는 실제 `BLINKERS`/`BLINKERS_ALT` 램프의 ON/OFF를 세고
기존 `ADRV_0x1ea.LEFT_BLINK_HOLD` 또는 `RIGHT_BLINK_HOLD`를 사용합니다.
새 SPAS 메시지나 주차보조 진단 명령은 추가하지 않습니다.

첫 ON/OFF를 확인한 뒤 연장을 허용하고, 다섯 번째 OFF에서 추가 유지 신호를
해제합니다. 차선변경이 시작되면 기존 모델 확률 0.9 초과 조건의 유지 로직에
맡기므로, 실제 차선변경 중 점멸 시간은 그 기존 로직을 따릅니다.

부팅 당시의 레버 카운트는 기준값으로만 사용합니다. CAN·모델·램프 정보 만료,
비상등·반대 방향 조작, 제어 해제 또는 점멸 진행 중단 시 추가 유지를 종료합니다.
개별 점멸을 구분할 수 없는 고정 램프 신호에는 연장을 적용하지 않습니다.

검증은 실제 `DesireHelper`, 네이티브 CAN pack/decode와 모델 메시지를 사용합니다.
실차에서 최종 점멸 횟수와 BCM의 유지 해제 반응을 확인해야 합니다.
