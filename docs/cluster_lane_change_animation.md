# EV6 차로변경 계기판 표시

정상 표시가 확인된 `5b7d02e205dd52d12262b51d7900e1409399e6a2`와
현재 브랜치를 비교했다. 정상 모델 입력에서는 `ADRV_0x161`의 전체 CAN
패킷이 동일했다. 기존 `LANELINE_*`, `LCA_*`, `LANE_LEFT/RIGHT` 값과
DBC 정의는 유지한다.

기존의 전역 25회 무효 카운터는 이전 정상 desire를 보관하지 않았다.
무효 메시지에 desire=0이 들어오면 표시가 즉시 꺼지고, 반대로 desire와
확률이 남아 있으면 깜빡이 유지까지 유예되는 문제가 있었다.

표시 보완은 차량 인스턴스별로 마지막 정상 desire와 실제 수신 시각을
보관하며, `0x161 LANE_LEFT/RIGHT`에만 사용한다. 수신 후 최대 0.25초이고
100Hz 루프에서 같은 메시지를 재사용해도 기간이 늘어나지 않는다.
정상 desire=0 또는 반대 방향이 새로 수신되면 즉시 반영한다.
횡제어 해제·CAN 무효·레버 완전 체결 시 캐시를 지우고, 다시 정상 메시지가
수신되기 전에는 이전 차로변경 표시를 되살리지 않는다. 완전 체결 시에도
현재 정상 턴 desire=1/2의 기존 표시는 유지한다.

`0x1EA` 차로변경 표시·경고·깜빡이 HOLD는 캐시를 사용하지 않으며,
모델 valid/alive가 무효이면 즉시 해제한다. 정상 상태의 HOLD 조건은
기존 모델 확률 `>0.9`다. 조향·ACC·BSD·레이더·원터치 횟수 정책은 변경하지 않는다.

검증은 실제 CAN 생성·해석과 `5b7d02e` 패킷 비교로 수행했다.
정상 패킷 비교 40건과 표시·깜빡이 경계 테스트 29건이 통과했다.
선택 회귀 테스트는 1,255건 통과했고, 원복한 기능의 기존 테스트 모듈 9개는
건너뛰었다. Hypothesis가 필요한 `test_hyundai.py`는 실행 환경에 패키지가 없어
이번 실행 대상에서 제외했다.
해당 실차에서 표시가 사라진 원인은 당시 모델/CAN 로그가 없어 확정하지 못했다.
