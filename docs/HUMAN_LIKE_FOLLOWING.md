# Human-Like Following 이식

`HumanLikeFollowing`을 켜면 확인된 전방 차량의 미래 움직임을 추종 계획에
반영합니다. 현재 레이더 측정값으로 미래 궤적의 시작 위치·속도를 고정한 뒤,
모델이 예측한 위치·속도 변화를 MPC의 추종 장애물 계산에 사용합니다.
앞차가 멀어질 것으로 예측되면 불필요한 제동을 일부 줄이고, 먼저 감속할
것으로 예측되면 더 일찍 감속할 수 있습니다. 항상 약하게 감속하는 기능은 아닙니다.

## 설정

- 콤마의 Carrot 설정 → Cruise: **휴먼라이크 앞차 추종**.
- JSON 기반 설정 메뉴: `selfdrive/carrot_settings.json`의 **차량간격 / FDIST**.
- `0`: OFF(기본값), `1`: ON. 두 메뉴는 같은 영구 저장 키를 사용합니다.
- 재부팅 없이 다음 주행 계획부터 반영합니다. 켤 때는 유효한 앞차 관측을
  다시 확인하며, 끄거나 제어가 초기화되면 이전 예측을 재사용하지 않습니다.

## 현재 브랜치에 맞춘 범위

`HumanLikeFollowing.update()`는 `radarState.mdMonoTime`과 정확히 일치하는
모델 프레임을 작은 캐시에서 찾습니다. 별도로 갱신되는 레이더와 모델의
최신 프레임 번호가 항상 같다고 가정하지 않습니다. 수신 시각, 예측 노출 시각,
확률·불확실도, 위치·속도·횡방향 일치, 동일 트랙의 연속 관측을 확인합니다.

현재 구현은 명시적으로 식별된 **전방 레이더 leadOne**에 적용합니다.
독립적인 코너레이더·정지차·끼어들기 **leadTwo**를 모델의 두 번째 예측과
같은 차량으로 간주하지 않습니다. 코너레이더 위험 감속과 기존 leadTwo 예측은
그대로 계산하며, 두 대상 중 더 제한적인 장애물이 계속 속도를 제한합니다.

정지·저속·밀착 차량, 강한 실측 감속/저크, 짧은 충돌 예상 시간, 확인 중인
해당 차량의 끼어들기, 위험 끼어들기, 빠져나가기, 차선변경, 운전자 개입,
신뢰할 수 없는 예측에서는 기존 레이더 예측으로 돌아갑니다. 즉, 끼어드는
차량의 최초 측면 감지나 긴급 대응을 이 기능으로 대체하지 않습니다.

낙관적인 예측으로 늘어나는 추종 장애물의 여유는 최대 **4m와 0.2초
차간거리 중 작은 값**으로 제한합니다. 처음 0.5초 구간에는 그 여유를 주지
않고 2초까지 점진적으로 반영합니다. 더 보수적인 예측 감속은 허용합니다.
기존 차간거리 설정, 가감속 한계, 물리 레이더 궤적을 사용하는 FCW 계산과
차량 AEB/CAN 송신 경로는 변경하지 않습니다.

## 원본과의 차이

기준 소스는 [FrogPilot c26a260](https://github.com/FrogAi/FrogPilot/blob/c26a2600419c4c79d38697d1d0ec4f89c733c91a/selfdrive/controls/lib/longitudinal_mpc_lib/long_mpc.py)와
[openpilot PR #37824](https://github.com/commaai/openpilot/pull/37824)의 최종
병합 코드입니다. 최종 방식은 위치와 속도의 변화를 함께 사용합니다.
위치를 미분해 속도를 만드는 방식은 PR 설명에 남아 있지만 최종 코드에서는
되돌려졌습니다. 2026년 7월 4일 버전의 잘못된 가짜 앞차 대체 경로도 이식하지 않았습니다.

FrogPilot은 자체 v9/v10 모델 목록으로 사용 여부를 제한합니다. 이 브랜치는
다른 모델 관리 방식과 사용자 모델 교체를 지원하므로 동일한 버전 목록을
그대로 적용하지 않았습니다. 대신 실제 출력의 형태·불확실도·물리적 일관성을
검사하고 여유를 제한합니다. 이는 해당 모델 버전과 동일한 예측 품질을
보장하는 검사가 아니므로 기본값을 OFF로 둡니다. 모델 파일은 교체하지 않습니다.

## 검증

- 신규 138개 테스트: 네이티브 cereal 메시지, 프레임 일치·만료·트랙 전환,
  켜기/끄기, planner 연결, MPC 여유 한계, leadTwo와 FCW 경로 검증.
- 실제 생성 C/Cython/acados solver 9,540회 계산: 모두 성공하고 유한한 출력.
- 별도로 내 차 100km/h, 새 앞차 90km/h에서 가속하는 25·30·35m 끼어들기
  시나리오 1,920회 계산도 성공했습니다. 30m 조건에서 최대 감속은
  -0.709→-0.658m/s², 최대 저크는 0.543→0.503m/s³로 줄었고 최소 간격은
  27.009→26.964m로 약 4.5cm 작아졌습니다. 초기 위험·leadTwo 제한 단계는
  기존과 같았습니다. 두 검증의 총 solver 계산은 11,460회입니다.
- 기존 업로드 로그 1,135프레임에서 OFF와 원래 MPC의 상태·출력·파라미터가
  비트 단위로 일치했습니다.
- ON 로그 재생에서는 조건을 만족한 예측 104개를 사용했고, FCW 카운트 차이와
  solver 실패가 없었습니다. 정지차·강한 감속 등 보호 조건도 비교했습니다.
- 넓은 회귀 검사에서 2,392개가 통과했습니다. 27개 실패는 앞선 메인 브랜치
  점검과 동일한 항목이며, 이번 기능과 별개로 남아 있습니다.

MPC 입력 재생과 단순 차량 운동 시뮬레이션 결과입니다. 전체 planner·차량
액추에이터·실차 도로 성능을 모두 검증한 결과는 아닙니다. 특정 시나리오의
개선 비율을 모든 끼어들기의 감속 감소율로 해석하지 않습니다.
전체 Qt 빌드와 실제 차량에서의 동작은 별도로 확인해야 합니다.
